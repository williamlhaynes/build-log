# build-log
Build-in-public log — what shipped, real numbers, what broke.

Entries live in `BUILD_LOG.md`, newest first.

**Entry format**

```
## YYYY-MM-DD — Entry title

**What shipped**
**Numbers (real ones only)**
**What broke**
```

"What broke" is mandatory. Numbers are only ones that can be verified, including
"$0 revenue" when that is the truth.

**Commit message format:** `Build log: YYYY-MM-DD — Entry title`
