# build-log
Build-in-public log: what I built, how it works, what you can take from it, real numbers, and what broke.

Entries live in `BUILD_LOG.md`, newest first.

**Entry format** (from 2026-10-05)

```
## YYYY-MM-DD — Entry title

**What I built**
**How it works**
**Take it**
**What I checked before shipping**
**Numbers (real ones only)**
**What broke**
**Next**
```

"Take it" is the reusable part: checks you can run against your own work and short
patterns you can copy. "What broke" is mandatory. Numbers are only ones that can be
verified, including "$0 revenue" when that is the truth. Entries before 2026-10-05
use the original three sections (What shipped, Numbers, What broke).

**Commit message format:** `Build log: YYYY-MM-DD — Entry title`
